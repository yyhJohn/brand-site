# CodeCat.dev — Brand Website

A premium dark-themed brand landing page for an AI-native product ecosystem.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** — blazing-fast build tool
- **Tailwind CSS v4** — utility-first styling
- **Framer Motion** — scroll animations & micro-interactions
- **Lucide React** — icon system

## Sections

| Section | Description |
|---------|-------------|
| **Navbar** | Sticky glassmorphic nav with logo, links, mobile menu |
| **Hero** | Full-screen with particle canvas, gradient orbs, animated text |
| **Products** | 6 product cards with glassmorphism, hover glow, status badges |
| **Technology** | Core capability cards with gradient icons |
| **Stats** | Animated counters (scroll-triggered) in a glass container |
| **Architecture** | Layered flow diagram from User → Data |
| **Brand Story** | AI-native philosophy statement |
| **CTA** | Contact + Explore call-to-action |
| **Footer** | Multi-column links with brand info |

## Products

1. **UniAPI** — Unified AI API Gateway (TypeScript, PostgreSQL, Stripe) — Active
2. **Auto Translator** — Cross-platform real-time translation (Swift, AI, macOS/iOS) — Active
3. **OpenClaw Gateway** — AI Agent orchestration (Node.js, Discord, Browser) — Active
4. **GPA Planner** — AI-powered study abroad planning (React, PostgreSQL, AI) — Beta
5. **Campus Match** — Campus social matching (React Native, Real-time, Maps) — Research
6. **Issue Reporting System** — Map-based issue management (Go, PostgreSQL, GIS) — Prototype

## Getting Started

```bash
npm install
npm run dev      # Development server
npm run build    # Production build
npm run preview  # Preview production build
```
